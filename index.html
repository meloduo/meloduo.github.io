What is in the studio

The agent uses the same studio you do. What it makes is a real project: notes you can move, sounds you can tweak, a mix you can rebalance.

The agent cannot hear, so it reads the render

The agent works through more than 60 tools: notes, channels, synths, drums, mixer, effects, automation, rendering. Before it decides, it renders the track and reads loudness, peaks, the spectrum and plain warnings that name the next step.

  • Undo per turnEverything the agent did in one turn goes back with one click while that turn is the latest change.
  • Your edits come firstIf you changed the project while it was thinking, its stale edit is rejected and it sees what you did.
  • All or nothingEach call applies fully or not at all.
  • Every edit says whyOne line in your language next to each change.
  • Producer skillsOne takes a track from an idea to a master in ten stages with checks. One designs sounds by trying variants.

How it connects, and what leaves your computer

Meloduo has no server and no accounts. The studio runs in your browser. A small bridge on your computer links it to the agent you already use.

Stays on your computer

  • Your projects, in this browser's storage
  • Your samples and exports
  • The audio: rendering and analysis run locally

Goes to your AI provider

  • The project state the agent reads: notes, channels, settings
  • Render reports: numbers, not audio
  • Your messages to the agent

What the agent cannot do through Meloduo

  • Open other projects in your library or import files
  • Add web plugins: it only turns the knobs of the ones you added
  • Make a change you cannot undo while the tab is open

GitHub hosts this site and, like any web host, sees your IP address. A web plugin you add yourself loads its code from the site you got it from.

Connect your agent

Want to try the studio first? Open the app: it works without an agent.

For the agent you need Node.js 20 or newer and any MCP client. The bridge runs on your computer and talks only to the Meloduo tab. What leaves your computer.

  1. Add the bridge to your client

    In a terminal
    claude mcp add meloduo -- npx -y @meloduo/mcp
    ~/.cursor/mcp.json
    {
  "mcpServers": {
    "meloduo": { "command": "npx", "args": ["-y", "@meloduo/mcp"] }
  }
}
    .vscode/mcp.json
    {
  "servers": {
    "meloduo": { "type": "stdio", "command": "npx", "args": ["-y", "@meloduo/mcp"] }
  }
}
    ~/.codex/config.toml
    [mcp_servers.meloduo]
command = "npx"
args = ["-y", "@meloduo/mcp"]
    Any client: a stdio server
    { "command": "npx", "args": ["-y", "@meloduo/mcp"] }

  2. Add the skills

    Two folders: one takes a track from an idea to a master in ten stages, one designs sounds by trying variants. Put them in your client's skills folder. A client without skills can read SKILL.md as instructions.

    Get the skills on GitHub

  3. Open the app and ask

    Open Meloduo, click once so the browser allows sound, and allow access to local devices if the browser asks. Then ask your agent for a track.

Know before you start

  • Public preview. Expect rough edges, and tell us what breaks.
  • Desktop Chrome or Edge. Other browsers and phones are not tested yet.
  • Your projects live in this browser. Clearing site data deletes them. Save a project file as a backup.
  • No built-in chat. Bring your own agent and its subscription.
  • No accounts, no cookies, no tracking. Meloduo has no server. Nothing leaves your browser except through the bridge you run.
  • No VST plugins yet. Browsers cannot run them. Web plugins in the WAM 2.0 format work.
Is it free?

Yes, and the studio stays free. You pay only for your own AI agent, if it is a paid one. Paid plans are planned for things that need a server: cloud sync and built-in models.

Does the agent make the whole song for me?

It can take a track from an idea to a master, but it works step by step in your project. You can stop it, edit its work, or undo its latest turn.

Which agents work?

Any client that speaks MCP. We test with Claude Code and Cline. The skills are plain SKILL.md folders, so other clients that read skills can use them too.

Where are my projects?

In your browser's storage on this computer. There is no cloud copy, so save project files for anything you care about.

Which browsers work?

Desktop Chrome and Edge are tested. Firefox and Safari may work but are not tested yet. Phones are not supported.

Does Meloduo send my music anywhere?

No. Meloduo has no server. Only your own agent sees the project state and render numbers, and sends them to the AI provider you chose. Audio never leaves your computer.

Will VST plugins work?

Not in the browser. VST support is planned through a desktop app. Until then, web plugins in the WAM 2.0 format load in the mixer.
